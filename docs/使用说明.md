## 手机上直接使用完整指令

将mobile/手机聊天指令.txt发给朋友。文件内包含入口、全部研究规范和17章模板，不依赖朋友读取本机C盘或拆解ZIP。能上传TXT则上传整份；否则按顺序粘贴全文。如果平台上下文限制导致内容不完整，不能声称已经加载完整Skill。

上传或粘贴后发送：

> 请完整读取我上传的A股研究指令，按其中证据分级、计算和17章报告规范研究全志科技（300458.SZ），投资周期1个月。先说明你实际可用的联网、原文读取、计算及文件保存能力，再展示研究计划。首页明确给出是否建议新增买入及对应原因、触发与失效条件；数据不足如实标记。请按本次实际日期重新采集，不沿用旧报告价格。

这相当于提供完整任务指令，不保证平台原生持久安装。没有联网能力不能主动收集实时资料；没有文件或持久存储能力时，要求交付可复制的证据与研究记忆并自行保存。

## Codex Cloud：本机关闭后使用

1. 使用本仓库Assozhu/a-share-research，根目录已包含AGENTS.md和.agents/skills/a-share-research/SKILL.md。
2. 在网页或桌面Codex创建Cloud环境，选择仓库；按环境实际能力安装Python及requirements.txt。
3. 运行python scripts/cloud_preflight.py和python -B -m unittest discover -s tests -v；检查联网权限和公开财报访问。不要把本地检查算作云端检查。
4. 审阅设置报告并发布；手机打开Codex，选择已发布的Cloud环境，再发送研究请求。
5. 重要报告和证据需要另行持久保存；个人账户和朋友账户不会自动共享环境或研究历史。

Cloud在云端执行，不依赖本机保持运行；选择“连接电脑”则仍需电脑在线。手机入口以账户、设备和工作区实际可用项为准。

## GitHub仓库与更新

仓库为Assozhu/a-share-research，保持Private。朋友可按需要获得访问，或单独接收downloads/a-share-research-native.zip和手机完整指令。分享ZIP/TXT不要求朋友拥有GitHub账号。仓库访问不会自动为朋友创建云端环境或开通行情。

仓库只保存Skill和交付方式，不是执行研究的服务。原始研究、个人附件、登录信息和本机设置不在包内。修改与更新后，各平台需重新导入或拉取版本；已有聊天上下文不会自动升级。
