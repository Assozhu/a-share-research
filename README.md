# A股公司研究 Skill

用于A股公司调研与投资价值分析，输出分级证据、可复算财务与估值、17章完整报告、明确的买入态度和观点失效条件。

版本：1.0.1-portable。沿用V1证据Schema与算分校验器，增加跨平台能力适配和17章交付规范。完整V1.1新Schema及计算器尚未全部实施。

## 选择使用方式

| 场景 | 入口 |
|---|---|
| Claude等支持标准Skill的Agent | [下载原生Skill ZIP](downloads/a-share-research-native.zip)，完整目录名为a-share-research |
| 豆包、普通千问及其他聊天界面 | [手机完整指令](mobile/手机聊天指令.txt)，上传文件或完整粘贴后发研究请求 |
| Kimi Agent | 通过/skill-creator将完整指令转为自定义Skill，检查规范未遗漏 |
| Claude Code / Qwen Code / Kimi Code | 解压原生ZIP，按[各平台使用说明](docs/使用说明.md)放置目录或指定加载目录 |
| 手机Codex、本机关闭后研究 | 为本仓库创建并发布Codex Cloud环境，使用[云端设置指令](docs/Codex云端设置.txt) |

## 开始研究

> 使用a-share-research研究全志科技（300458.SZ），投资周期1个月。先展示研究计划，并按17章输出完整报告。首页明确是否建议新增买入、对应原因、置信度、触发与失效条件；每个事实附原始来源。按本次真实日期采集，数据不足如实列明。

用户要求确认研究计划时等待；已有授权后继续研究，不重复停在计划。

## Codex Cloud

在网页或桌面Codex创建Cloud环境并选择本仓库。让设置会话安装requirements.txt，运行离线预检、规则测试及真实公开财报联网预检；审阅结果后发布。手机选择已发布的Cloud环境执行，云端方式无需本机保持开机。选择“连接电脑”方式时，电脑仍需在线。

Skill入口：[.agents/skills/a-share-research/SKILL.md](.agents/skills/a-share-research/SKILL.md)。代码校验依赖Python，PDF解析使用pypdf；网络访问与工具能力需在实际环境检查。本地检查不等于云端执行验收，当前云端尚未部署。

## 分享与历史

仓库是私有的。朋友需要得到仓库访问权限，或由你直接发送下载的ZIP/TXT；他们使用自己的Agent和账号。GitHub只托管文件，不执行研究，不自动共享登录、行情订阅或研究历史。首次取得文件后可离线保存规则，实时研究仍需其Agent具备联网能力。

研究结果保存为版本化research目录，默认被.gitignore排除。需要长期复盘时另行选择持久存储；没有文件能力时交付可复制的研究记忆，不宣称已自动保存或监控。
