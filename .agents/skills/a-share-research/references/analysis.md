# 分析口径

## 行业与公司

行业规模标明定义、币种、区域、年份与实际/预测，不拼接不同口径增长率。产业链受益须具体到产品、客户、份额、供给和订单转化，不推断未公开客户。治理查控股股东、实控人、股权激励、质押、关联交易、审计及监管；“未找到处罚”不等于确认无处罚。

## 财务

- 最近8个已披露季度；不足8季时保存实际覆盖和原因。流量区分累计与单季；Q2=半年累计−Q1，Q3=前三季累计−半年累计，Q4=全年−前三季。同口径/同合并范围/同单位才能相减。资产负债表为时点存量，不能作季度差分。
- TTM=最新全年+本年最新累计−去年同期间累计；不把半年翻倍当TTM，也不把两个累计报告相加。全部输入追溯到证据ID。
- 使用归母利润、扣非归母利润和总净利润时分别命名。ROE采用披露口径或明确平均归母净资产；合并现金流/归母利润只是代理指标，披露其口径差异。
- 毛利率=(收入−营业成本)/收入；净利率注明利润口径；同比=(本期/可比上期−1)×100%，零/负基数导致不适用时注明；百分点差=两个百分比相减。
- 优先比较现金流、应收与存货周转、资本开支、减值、补助、非经常损益和税率。一次性税收影响不能直接外推持续盈利。
- 更正和重述使用截至研究日可获的最新可比数据。送转引起EPS重述不意味着实际利润同步变动，不能将重述前后EPS直接同比。8季表需保留原值、衍生值标记及来源。

## 市场行为

价格注明行情截至日期及收盘/盘中、币种和复权方式。真实成交量与服务商“主力资金流”模型分开，后者不等于真实资金主体成交。换手率记录流通股口径，波动率记录采样周期、收益类型、样本数与年化因子。个股相对指数表现使用相同交易日期和可比复权数据；除权跌幅不能当经济亏损。

最近15天是事件自然日窗口，不是15个交易日。均线、波动率和历史分位需要更长交易日序列时在计划中扩窗。停牌、涨跌停、交易规则、行业指数成分等需实时核验原始规则，不能凭固定记忆断言。没有足够行情时不形成技术位、成交趋势或机会总分。

## 估值方法选择

选1–2项主要方法及适用时的交叉检验，不强行全部计算。成长科技用PE/PEG并在现金流预测可靠时使用DCF；金融通常PB+ROE；周期企业用跨周期利润、EV/EBITDA并查峰值盈利；亏损公司PE/PEG不适用，PS仍需检查利润率及融资需求。

| 方法 | 算式 | 必须说明 |
|---|---|---|
| PE | 同时点总市值/归母净利润TTM，或价格/EPS TTM | 静态、TTM和预测分别标记；负/零利润不输出普通PE |
| PB | 市值/对应股本口径归母净资产 | 股本与资产时点、资产质量、净资产非正时不适用 |
| PS | 市值/营业收入TTM | 收入质量及商业模式，不把低PS自动解释为便宜 |
| PEG | PE/盈利年增长率的百分数值 | 增长20%分母用20；期数、实际/预测、一次性影响；非正增长不适用 |
| EV/EBITDA | EV/对应期EBITDA | EV=股权市值+有息债务+优先权益+少数股东权益−可扣减现金；全部口径列明，不用总负债代替有息债务 |
| DCF | Σ FCFF_t/(1+WACC)^t + TV/(1+WACC)^N；TV=FCFF_N×(1+g)/(WACC−g) | 明确FCFF口径、预测年、WACC、g；WACC>g；从EV扣净债务、少数权益等转换为股权价值及每股价值 |
| 股息率 | 对应期每股现金股息/同一时点价格 | 税前/税后、过去12月/已宣告/预测，已支付分红不当未来催化 |

DCF预测期是模型需要的期限，不等于用户持有期限；不拿长期DCF终值证明3个月价格会兑现。无法确定WACC、资本开支、债务或股本时不输出精确DCF价。

每个模型保存证据输入、假设、公式、计算、单位、时点和舍入。情景至少说明悲观/基准/乐观的变动驱动；没有概率依据不编造概率或概率加权收益。目标价应是条件下的区间，盈利及估值倍数都须有依据；基础数据不足就不给区间。

历史估值分位记录频率、起止日、复权与财务口径、样本数及重述处理，不用单日截图宣称近5年分位。可比公司说明业务、客户、成长、利润率与会计口径，不能只按板块标签选择。
